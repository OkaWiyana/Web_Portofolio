# 📄 My Portfolio Website

This is the repository for my personal portfolio website, where I showcase my projects, skills, and experiences as a Web Developer and UI/UX Designer.


## 🚀 Features

- **Responsive Design**: Fully responsive for all device sizes (mobile, tablet, and desktop).
- **Modern UI/UX**: Designed with modern UI/UX principles using Poppins font and Tailwind CSS for styling.
- **Projects Showcase**: Highlight of key web development and UI/UX design projects.
- **Contact Form**: Users can contact me directly through a form.
- **Social Media Integration**: Links to social media profiles such as Instagram and LinkedIn.
  
---

## 🛠️ Technologies Used

- **Frontend**: 
  - HTML
  - CSS (Tailwind CSS)
  - JavaScript (React.js)
  
- **Frameworks**:
  - Tailwind CSS for responsive and modern designs.
  
- **Version Control**:
  - Git & GitHub for project versioning.
